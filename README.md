# Six circles in a rectangle

Figures for a pure-geometry answer ([answer](https://mathoverflow.net/a/515659)) to the MathOverflow question
[Six circles in a rectangle: show that two lengths are equal, using pure geometry](https://mathoverflow.net/q/515498).

- `figures/fig1_setup.png`: the configuration and notation
- `figures/fig2_bisector.png`: OM bisects angle U O B_t
- `figures/fig3_parallel.png`: A_t, T, C'_b collinear, parallel to OM; AC' parallel to OB_t
- `figures/fig4_midpoint.png`: the midpoint S of AC', and the line meeting the midline at E'
- `figures/fig5_finish.png`: the tangent-chord angle at E' puts A on the circle Omega

All figures are drawn to scale from the configuration solved numerically to 50 digits.
